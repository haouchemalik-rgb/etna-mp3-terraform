1. Qu'est-ce que l'Infrastructure as Code (IaC) ?
L’Infrastructure as Code (IaC) est une méthode de gestion et de provisioning des ressources informatiques via du code. Plutôt que de configurer manuellement des serveurs ou des services, l'IaC permet de les décrire et de les gérer à l'aide de fichiers texte. Cela garantit la reproductibilité, l'efficacité et la possibilité de versionner les configurations comme on le ferait pour du code.

2. À quoi sert Terraform ?
Terraform est un outil d’Infrastructure as Code (IaC) open-source qui permet de provisionner et de gérer des infrastructures à travers plusieurs fournisseurs cloud (AWS, Azure, GCP). Il permet de créer, mettre à jour, et versionner des configurations d'infrastructure de manière déclarative à partir de fichiers de configuration.

3. Qu'est-ce qu'un provider Terraform ?
Un provider Terraform est un plugin qui permet à Terraform d'interagir avec différentes API cloud. Chaque provider (comme AWS, Azure, GCP) contient les ressources et les fonctionnalités spécifiques pour provisionner et gérer des services sur cette plateforme.
